# Chạy bản thử nghiệm

1. Từ thư mục dự án, chạy python app.py.
2. Mở http://127.0.0.1:8000.
3. Lần đầu, đặt mật khẩu tài khoản chủ quán qua màn hình thiết lập.
4. Tạo danh mục hàng, nhân viên, ca tiền và ca làm.
5. Cuối ca, nhập tổng kết CUKCUK và tiền thực đếm; xem dashboard chênh lệch.

Dữ liệu nằm trong data/restaurant.db. Sao lưu bằng cách dừng ứng dụng và sao chép file này vào vị trí an toàn. Không mở cổng Internet trực tiếp; khi dùng nhiều thiết bị, cấu hình HTTPS và quyền truy cập mạng nội bộ.
